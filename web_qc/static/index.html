Guideline

        
Tải file guideline (PDF, DOCX, TXT, MD) để tra cứu khi xem lỗi. Thêm file luật để tool tự kiểm tra theo guideline (tầng 1) và ghi số mục vào Issue.

Các khoá trong file luật
              
    
                
  • loai_tool: tool hiểu nhãn này là gì (car, truck, bus, motorcycle, bicycle, person, GreenSM).

  • khong_de_mac_dinh: thuộc tính còn giá trị mặc định thì báo "không chắc".

  • muc: số mục guideline, được ghi vào Issue.

Kết nối CVAT

        
Đổi job hoặc máy CVAT: sửa CVAT_URL, CVAT_TOKEN, CVAT_TASK_ID, CVAT_JOB_ID trong file cvat_2d/.env trên máy chủ, rồi tải lại trang. Token không bao giờ hiện lên trình duyệt.
